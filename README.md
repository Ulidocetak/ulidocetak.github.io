## Catatan harga
Harga yang tampil masih berupa **estimasi awal / harga mulai** untuk kebutuhan demo website. Produk custom seperti neon box, backdrop, roll banner, buku, dan pekerjaan khusus ditampilkan sebagai **Konsultasi** karena harga sangat bergantung pada ukuran, bahan, finishing, dan jumlah.

Untuk mengganti dengan harga resmi, edit `PRODUCTS` dan `CALCULATOR_DATA` pada `script.js`.
